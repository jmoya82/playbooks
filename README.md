<h1 align="center">
  Playbooks
</h1>

```playbooks``` is the community playbook repository for [Oreol CLI](https://github.com/oreolag/cli/tree/main)-based clusters. Each playbook provides reproducible automation for configuring, managing, and maintaining heterogeneous on-premises infrastructure, helping administrators prepare servers, configure networking, and manage system services.

Using ```odev``` GitHub integration, users can share playbooks with the community and contribute to an open ecosystem of reusable automation for modern accelerated computing platforms.
