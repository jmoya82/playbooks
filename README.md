<h1 align="center">
  Playbooks
</h1>

```playbooks``` is the community playbook repository for [Oreol CLI](https://github.com/oreolag/cli/tree/main)-based clusters. Each playbook provides reproducible automation for preparing cluster resources to run accelerated applications, helping developers program FPGAs, configure network interfaces, and apply application-specific settings across heterogeneous hardware.

Using ```odev``` GitHub integration, developers can share playbooks with the community and contribute to an open ecosystem of reusable automation for modern accelerated computing platforms.
